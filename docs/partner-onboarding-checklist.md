# Partner Onboarding Checklist

## Identity

- Partner legal name recorded.
- Technical contact recorded.
- Operational contact recorded.
- Tenant or global integration scope identified.

## Legal and Approval

- Data sharing purpose approved.
- Scope list approved.
- Sensitive data review completed.
- Go-live owner assigned.

## Technical Setup

- API client created.
- Tenant assigned when applicable.
- Required scopes granted.
- Rate limit configured.
- IP allowlist configured if partner has fixed outbound IPs.
- Token generated and handed over through a secure channel.

## Webhook Setup

- Endpoint URL registered.
- Secret configured.
- Event subscriptions selected.
- Test delivery completed.
- Retry behavior reviewed.

## Security Verification

- Partner confirms token storage policy.
- Partner confirms webhook signature verification.
- Tenant isolation smoke test completed.
- Forbidden scope smoke test completed.
- Token revoke test completed.

## Go-Live

- API docs shared.
- Support escalation path shared.
- Monitoring owner assigned.
- Go-live approval recorded.
