# Customer Onboarding Playbook

## Flow

1. Lead masuk.
2. Demo dijadwalkan.
3. Proposal dikirim.
4. Agreement.
5. Data collection.
6. Tenant configuration.
7. Admin/guru training.
8. Pilot data kecil.
9. Go-live.
10. Handover ke support.

## Data Collection

- Data sekolah.
- Data admin.
- Data kelas.
- Data guru.
- Data santri.
- Data orang tua.
- Modul yang aktif.
- Branding dasar.

## Go-Live Gate

Go-live hanya dilakukan setelah checklist required selesai, parent portal diuji, workflow tahfizh diuji, report diuji, dan backup diuji.
