# Kebijakan Tugas Ringan LMS (LMS Assignment Lite Policy)

## Alur Pengumpulan Tugas
1. **Pengumpulan:** Siswa mengisi teks tanggapan atau mengunggah berkas lampiran pendukung.
2. **Auto-Complete:** Pengumpulan tugas secara otomatis menandai status materi pelajaran terkait menjadi **Selesai** (Complete).
3. **Penilaian:** Guru pengampu memeriksa pengumpulan tugas, memberikan skor (0 - Nilai Maksimum), serta memberikan umpan balik (feedback).
4. **Notifikasi:** Setelah guru memberikan nilai, sistem akan otomatis mengirimkan notifikasi internal kepada santri dan wali murid.
