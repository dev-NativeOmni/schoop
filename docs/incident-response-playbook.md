# Incident Response Playbook

## Severity

- SEV1: data leak, security breach, saldo/transaksi salah besar, production down.
- SEV2: fitur utama down untuk banyak user.
- SEV3: gangguan tenant tertentu dengan workaround.
- SEV4: minor incident.

## Flow

1. Buat incident report.
2. Tetapkan owner.
3. Catat timeline.
4. Mitigasi awal.
5. Komunikasi ke sekolah terdampak.
6. Root cause analysis.
7. Corrective action.
8. Close setelah validasi.
