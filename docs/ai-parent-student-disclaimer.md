# AI Parent & Student Disclaimer Policy

Kebijakan penyematan teks sanggahan keselamatan (disclaimer) pada seluruh tampilan portal orang tua dan siswa.

## Teks Disclaimer Wajib (Bahasa Indonesia)
> "Rekomendasi ini dibuat oleh sistem untuk membantu proses belajar dan telah/harus direview oleh guru. Keputusan pembelajaran tetap mengikuti arahan guru."

## Aturan Penyematan
1. Teks disclaimer di atas wajib ditampilkan secara jelas dan terbaca pada bagian bawah setiap kartu asisten rekomendasi, practice plan, atau ringkasan profil belajar.
2. Ukuran teks sanggahan diatur menggunakan class CSS berukuran kecil (seperti `text-xs` atau `text-[10px]`) dan berwarna abu-abu redup (seperti `text-slate-400` atau `text-slate-450`) untuk menjaga estetika visual premium tanpa mengaburkan pesan utama.
3. Seluruh teks sanggahan disisipkan secara otomatis oleh `AiSafetyGuardService` sebelum data dikirimkan ke portal.
